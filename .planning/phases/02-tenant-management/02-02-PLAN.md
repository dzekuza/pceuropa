  <action>
**1. Create `lib/utils/calculations.ts`** — Pure calculation functions.
- `calculatePK(rentEur: number | null, spaceM2: number | null): number | null` — Returns `rentEur / spaceM2` or `null` if either is null/zero. This is constant per tenant (does not vary by month).
- `calculateApyvartaPerM2(amountEur: number, spaceM2: number | null): number | null` — Returns `amountEur / spaceM2` or `null` if spaceM2 is null/zero. Per-month calculation.
- `calculateEfektyvumas(amountEur: number, rentEur: number | null): number | null` — Returns `(amountEur / rentEur) * 100` or `null` if rentEur is null/zero. Per-month calculation.
- All functions guard against division by zero: check for null, undefined, 0 before dividing.

**2. Create `components/tenants/tenant-detail-header.tsx`** — Server Component.
- Renders a shadcn `Card` with tenant info: Parduotuvė (store_name), Operatorius (operator), Kategorija (category), Plotas (space_m2 + "m²"), Nuomos kaina (rent_eur + "€/mėn.")
- Layout: horizontal grid of key-value pairs on desktop (4 columns), stack on mobile
- All labels in Lithuanian
- Include a back link/button "← Nuomininkai" that navigates to `/admin/tenants`

**3. Create `components/tenants/year-selector.tsx`** — Client Component (`'use client'`).
- Props: `currentYear: number`
- Renders a shadcn `Select` with years from `currentYear - 2` to `currentYear + 1`
- On year change: uses `router.push` to navigate to same page with `?year=YYYY` query param
- Label: "Metai" (Year)
- Default value: currentYear

**4. Create `components/tenants/tenant-revenue-table.tsx`** — Server Component.
- Props: `tenant` (tenant row), `reports` (revenue_reports array for the year), `year` (number)
- Uses `MONTHS_LT` from `lib/constants.ts` for month names
- Generates all 12 month rows (Sausis through Gruodis)
- For each month, merges with matching revenue report (match by month date `YYYY-MM-01`)
- Columns in order:
  1. **Mėnuo** — Month name in Lithuanian
  2. **Nuomuojamas plotas (m²)** — `tenant.space_m2` (same for all months)
  3. **Pirkimų sk.** — `report.tx_count` or 0 if no data
  4. **Apyvarta (EUR)** — `report.amount_eur` or 0.00 if no data
  5. **P.K (EUR/m²)** — `calculatePK(tenant.rent_eur, tenant.space_m2)` — constant, show dash "—" if null
  6. **Apyvarta (EUR/m²)** — `calculateApyvartaPerM2(amount, tenant.space_m2)` — show dash "—" if no data or null
  7. **Efektyvumas (%)** — `calculateEfektyvumas(amount, tenant.rent_eur)` — show dash "—" if no data
- Auto-calculated columns (P.K, Apyvarta/m², Efektyvumas) have a subtle background tint: `bg-muted/50` or similar
- Efektyvumas color coding using Badge or inline styles:
  - Green (`bg-green-100 text-green-800`): >= 100%
  - Yellow (`bg-yellow-100 text-yellow-800`): 70-99%
  - Red (`bg-red-100 text-red-800`): < 70%
  - Dash for null/no data (text-muted-foreground)
- Months with no submitted data: show `0` for tx_count, `0.00` for amount_eur, "—" for calculated columns where input is zero
- **Vidurkis (average) row** at bottom in `<tfoot>`:
  - Average only over months that have submitted data (ignore zero months)
  - If no months have data, show "—" across all average cells
  - Style: bold text, top border separator
- Format EUR values to 2 decimal places, percentages to 1 decimal place
- Use shadcn `Table`, `TableHeader`, `TableRow`, `TableHead`, `TableBody`, `TableCell`

**5. Create `app/(dashboard)/admin/tenants/[id]/page.tsx`** — Server Component.
- Verify admin via `getUser()` + app_metadata role check → redirect to `/login` if not admin
- Read `params.id` for tenant ID (await params in Next.js 15 style)
- Read `searchParams.year` for year (default to current year if not provided)
- Fetch tenant: `supabase.from('tenants').select('*').eq('id', params.id).single()`
- If tenant not found: redirect to `/admin/tenants`
- Fetch revenue reports for the year: `supabase.from('revenue_reports').select('*').eq('tenant_id', params.id).gte('month', '${year}-01-01').lte('month', '${year}-12-31')`
- Use `Promise.all` for parallel fetches
- Render: `<TenantDetailHeader>`, `<YearSelector>`, `<TenantRevenueTable>`
- Page padding consistent with dashboard layout
