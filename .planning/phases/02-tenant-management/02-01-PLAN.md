**1. Create `lib/supabase/admin.ts`** — Service role admin client (server-only, never Client Component).

- Type with `Database` from `@/types/database`
- Export `createAdminClient()` function

**2. Create `lib/constants.ts`** — Lithuanian constants shared across components.
- `TENANT_CATEGORIES` array: `['Mada ir apranga', 'Maistas ir restoranai', 'Elektronika', 'Sportas ir laisvalaikis', 'Grožis ir sveikata', 'Namų apyvoka', 'Žaislai ir vaikų prekės', 'Juvelyrika ir aksesuarai', 'Paslaugos', 'Kita']`
- `MONTHS_LT` array: `['Sausis','Vasaris','Kovas','Balandis','Gegužė','Birželis','Liepa','Rugpjūtis','Rugsėjis','Spalis','Lapkritis','Gruodis']`

**3. Create `lib/validations/tenant.ts`** — Zod schema for tenant form.
- Fields: `username` (min 3, Lithuanian error), `password` (min 6, Lithuanian error), `store_name` (min 1), `operator` (optional string), `company_code` (optional string), `category` (min 1, "Pasirinkite kategoriją"), `space_m2` (coerce number, positive), `rent_eur` (coerce number, positive)
- Export the schema AND the inferred type `TenantFormValues`
- All validation messages in Lithuanian

**4. Create `actions/tenants.ts`** — Three Server Actions with `'use server'` directive.

`createTenant(formData: TenantFormValues)`:
- Defense-in-depth: verify caller is admin via `getUser()` + `app_metadata.role === 'admin'`
- Step 1: `adminClient.auth.admin.createUser()` with `email: ${username}@pceuropa.lt`, `password`, `email_confirm: true`, `app_metadata: { role: 'seller' }`
- Step 2: Insert into `tenants` table with `user_id` from step 1
- If step 2 fails: delete orphaned auth user with `adminClient.auth.admin.deleteUser()`
- Call `revalidatePath('/admin/tenants')` on success
- Return `{ success: true }` or `{ error: string }` with Lithuanian messages

`updateTenant(tenantId: string, formData: Partial<...>)`:
- Verify admin. Update `tenants` row via `supabase.from('tenants').update().eq('id', tenantId)`
- `revalidatePath('/admin/tenants')` on success
- Do NOT update auth user email/password in edit (only tenant record fields)

`deleteTenant(tenantId: string)`:
- Verify admin. Fetch tenant's `user_id` first
- Delete tenant row, then delete auth user via `adminClient.auth.admin.deleteUser()`
- `revalidatePath('/admin/tenants')` on success
