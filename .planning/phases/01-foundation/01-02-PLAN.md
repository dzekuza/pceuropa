**Step 1: Project scaffold** (if not already scaffolded)
Run the shadcn Nova preset bootstrap command from 01-RESEARCH.md:
```

```
Then install Supabase packages: `npm install @supabase/supabase-js @supabase/ssr`

**Step 2: Supabase client split** (Pattern 1 from RESEARCH)
- `lib/supabase/client.ts`: Export `createClient()` using `createBrowserClient<Database>` with NEXT_PUBLIC env vars. For Client Components only.
- `lib/supabase/server.ts`: Export async `createClient()` using `createServerClient<Database>` with `cookies()` from `next/headers`. For Server Components, Server Actions, Route Handlers.
- Both import `Database` type from `@/types/database`.

**Step 3: Auth utilities**
- `lib/auth/get-role.ts`: Export `getRole()` — calls `getUser()` (NOT getSession), returns `'admin' | 'seller' | null` from `app_metadata.role`.
- `actions/auth.ts`: Server Action `logout()` — calls `supabase.auth.signOut()` then `redirect('/login')`. Mark with `'use server'`.
- `lib/strings.ts`: Export all Lithuanian string constants:
  - `ADMIN_NAV_ITEMS` array: [{label: 'Nuomininkai', href: '/admin/tenants', icon: 'Building2'}, {label: 'Analitika', href: '/admin/analytics', icon: 'BarChart2'}, {label: 'DUK', href: '/admin/faq', icon: 'HelpCircle'}, {label: 'Nustatymai', href: '/admin/settings', icon: 'Settings'}]
  - `SELLER_NAV_ITEMS` array: [{label: 'Apyvarta', href: '/seller/revenue', icon: 'TrendingUp'}, {label: 'DUK', href: '/seller/faq', icon: 'HelpCircle'}]
  - `AUTH_STRINGS` object: loginTitle 'Prisijungti', usernameLabel 'Vartotojo vardas', passwordLabel 'Slaptažodis', loginButton 'Prisijungti', loginError 'Neteisingas vartotojo vardas arba slaptažodis', logoutLabel 'Atsijungti'
  - `SELLER_USERNAME_DOMAIN`: '@pceuropa.lt' — used when appending domain to seller username for Supabase auth email field

**Step 4: proxy.ts middleware** (Pattern 2 from RESEARCH)
Create `proxy.ts` (NOT middleware.ts — Next.js 16 filename). Must:
- Create Supabase server client with request cookies adapter
- Call `getUser()` (NEVER getSession) for JWT validation + token refresh
- Redirect unauthenticated users on /admin/* or /seller/* to /login
- Redirect authenticated users on /login to their role-appropriate dashboard (/admin or /seller)
- Enforce role: seller on /admin/* → redirect to /seller
- CRITICAL: Return `supabaseResponse` (not `NextResponse.next()`) so refreshed cookies propagate
- Matcher: exclude _next/static, _next/image, favicon.ico, static assets

**Step 5: Auth callback route** (Pattern 5 from RESEARCH)
Create `app/auth/callback/route.ts` with GET handler:
- Extract `code` from searchParams
- Create Supabase server client, call `exchangeCodeForSession(code)`
- Redirect to /admin (middleware will handle role-based routing)
