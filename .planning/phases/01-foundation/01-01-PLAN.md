<task type="auto">
  <name>Task 1: Create Supabase migration with full schema and RLS policies</name>
  <files>supabase/config.toml, supabase/migrations/001_initial_schema.sql</files>
  <action>
Initialize the local Supabase project structure with `npx supabase init` (creates supabase/ directory with config.toml).

Then create the migration file `supabase/migrations/001_initial_schema.sql` containing ALL three tables with RLS enabled AND policies in the same file — never leave a table with RLS on and no policies.

**tenants table:**
- id (uuid PK, gen_random_uuid), user_id (uuid FK → auth.users ON DELETE CASCADE), store_name (text NOT NULL), operator (text), company_code (text), category (text), space_m2 (numeric), rent_eur (numeric), created_at (timestamptz DEFAULT now())
- RLS policy "tenants_admin_all": FOR ALL TO authenticated USING app_metadata.role = 'admin'
- RLS policy "tenants_seller_own_select": FOR SELECT TO authenticated USING role = 'seller' AND user_id = auth.uid()

**revenue_reports table:**
- id (uuid PK), user_id (uuid FK → auth.users ON DELETE CASCADE), tenant_id (uuid FK → tenants ON DELETE CASCADE), month (date NOT NULL), amount_eur (numeric NOT NULL), tx_count (integer), submitted_at (timestamptz DEFAULT now()), UNIQUE(tenant_id, month)
- RLS policies: admin_all (FOR ALL, role=admin), seller_own_select (FOR SELECT, user_id=auth.uid()), seller_own_insert (FOR INSERT WITH CHECK role=seller AND user_id=auth.uid()), seller_own_update (FOR UPDATE, user_id=auth.uid() AND role=seller)

**faq_items table:**
- id (uuid PK), question (text NOT NULL), answer (text NOT NULL), sort_order (integer DEFAULT 0), created_at (timestamptz DEFAULT now())
- RLS policies: admin_all (FOR ALL, role=admin), authenticated_select (FOR SELECT, USING true — all authenticated users can read)

**Indexes:**
- tenants(user_id), revenue_reports(user_id), revenue_reports(tenant_id, month), faq_items(sort_order)

Use exact RLS pattern: `(auth.jwt() -> 'app_metadata' ->> 'role') = 'admin'` — NOT user_metadata.

Reference Pattern 7 in 01-RESEARCH.md for the complete SQL.
  </action>
