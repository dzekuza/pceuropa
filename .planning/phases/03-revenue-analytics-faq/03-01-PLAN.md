Create `submitRevenue` Server Action:
1. Create supabase client via `createClient()` from `@/lib/supabase/server`
2. Defense-in-depth: call `getUser()`, verify `app_metadata.role === 'seller'` — return Lithuanian error if unauthorized
3. Fetch the seller's tenant record via `supabase.from('tenants').select('id').eq('user_id', user.id).single()` — need tenant_id for the revenue_reports FK

6. `revalidatePath('/seller/revenue')` on success

Follow existing patterns from `actions/tenants.ts` for error handling style and return types.

**app/(dashboard)/seller/revenue/page.tsx** (Server Component):
1. Auth guard: `getUser()` + verify `app_metadata.role === 'seller'`, redirect to `/login` if unauthorized
2. Fetch seller's tenant record: `supabase.from('tenants').select('id').eq('user_id', user.id).single()` — redirect to `/seller` if no tenant found
3. Fetch all revenue_reports for this tenant: `supabase.from('revenue_reports').select('*').eq('tenant_id', tenant.id).order('month', { ascending: false })`
4. Render page title "Apyvartos pateikimas" with subtitle "Pateikite menesinius pardavimu duomenis"
5. Render `<RevenueForm reports={reports ?? []} />` and `<SubmissionHistory reports={reports ?? []} />` — the form needs reports to detect already-submitted months

**components/revenue/revenue-form.tsx** ('use client'):
1. Props: `{ reports: RevenueReport[] }` from `types/database`
2. State: `selectedMonth` (string "YYYY-MM") — default to current month `${new Date().getFullYear()}-${String(new Date().getMonth() + 1).padStart(2, '0')}`
3. Month dropdown (shadcn Select): generate options for last 12 months. Each option label from `MONTHS_LT[monthIdx] + ' ' + year`. Disabled months: none (allow re-selection for editing).
4. Detect if selectedMonth has existing report: `reports.find(r => r.month.startsWith(selectedMonth))`. If found, show info badge "Redaguojate jau pateiktus duomenis" (styled with subtle blue bg) and pre-fill form with `amount_eur` and `tx_count` from that report.
5. react-hook-form with zodResolver(revenueFormSchema). Fields: Apyvarta (EUR) — Input type="text" inputMode="decimal", Pirkimu sk. — Input type="text" inputMode="numeric".
6. On submit: call `submitRevenue(formData)` Server Action. Show toast-like success/error feedback using a state message (or use sonner if available — check package.json; if not installed, use a simple state-based alert below the button).
7. After successful submit, call `router.refresh()` to re-fetch data (since this is a Client Component calling a Server Action, use `useRouter` from `next/navigation`).
8. Submit button text: "Pateikti" (or "Atnaujinti" if editing existing month).
9. Inline field validation errors in Lithuanian below each input (react-hook-form `formState.errors`).
10. Expose `onSelectMonth` callback so SubmissionHistory can set selected month from outside — lift state to parent OR use a shared callback prop pattern. Simplest: make the page a Client Component wrapper that holds selectedMonth state and passes it to both. OR: keep page as Server Component and make a client wrapper component `revenue-page-client.tsx` that holds state for both children.

**Decision (Claude's discretion):** Create `components/revenue/revenue-page-client.tsx` as a thin 'use client' wrapper that holds `selectedMonth` state and renders both RevenueForm and SubmissionHistory. The Server Component page passes reports and renders this wrapper.

**components/revenue/submission-history.tsx** ('use client'):
1. Props: `{ reports: RevenueReport[], onSelectMonth: (month: string) => void }`
2. Simple table using shadcn Table components: columns Menuo (formatted from MONTHS_LT), Apyvarta (EUR) (formatted with .toFixed(2)), Pirkimu sk., Pateikta (date formatted as YYYY-MM-DD)
3. Clicking a row calls `onSelectMonth(report.month.slice(0, 7))` — this triggers form pre-fill in the parent
4. Empty state: "Dar nepateikta jokiu duomenu" centered text when reports is empty
5. Sort reports by month descending (most recent first)
