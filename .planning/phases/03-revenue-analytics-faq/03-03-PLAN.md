**lib/validations/faq.ts:**
Zod v4 schema `faqFormSchema`:
- `question`: z.string().min(3, 'Klausimas per trumpas') — minimum 3 chars
- `answer`: z.string().min(3, 'Atsakymas per trumpas') — minimum 3 chars
Export `FaqFormValues` type.

**actions/faq.ts:**
All Server Actions follow existing pattern from `actions/tenants.ts` — defense-in-depth admin guard via `getUser()` + `app_metadata.role === 'admin'`.

1. `createFaqItem(formData: FaqFormValues)`: Insert into faq_items. Auto-assign `sort_order` = max existing sort_order + 1 (query `select('sort_order').order('sort_order', { ascending: false }).limit(1)` first). `revalidatePath('/admin/faq')`.

2. `updateFaqItem(id: string, formData: FaqFormValues)`: Update question + answer by id. `revalidatePath('/admin/faq')`.

3. `deleteFaqItem(id: string)`: Delete by id with admin guard. `revalidatePath('/admin/faq')`.

4. `reorderFaqItems(orderedIds: string[])`: Receives array of FAQ item IDs in desired order. Updates `sort_order` for each item to match its array index. Use a loop with individual updates (simple, reliable — FAQ list is small, typically <20 items). `revalidatePath('/admin/faq')`. Also `revalidatePath('/seller/faq')` so seller view updates.

**app/(dashboard)/admin/faq/page.tsx** (Server Component):
1. Auth guard: admin role check, redirect to `/login` if unauthorized
2. Fetch: `supabase.from('faq_items').select('*').order('sort_order', { ascending: true })`

**components/faq/faq-admin-list.tsx** ('use client'):
1. Props: `{ items: FaqItem[] }`
2. State: local copy of items for optimistic reorder
3. Renders a vertical list of cards. Each card shows:
   - Question (bold) and answer (below, truncated to 2 lines with ellipsis)
   - Action buttons on the right: Edit (pencil icon), Delete (trash icon), Move Up (chevron-up), Move Down (chevron-down)
   - Move Up disabled on first item, Move Down disabled on last item
4. Move up/down: swap items in local state (optimistic), call `reorderFaqItems(newOrderedIds)` Server Action
5. Edit button: opens FaqFormDialog in edit mode with pre-filled values
6. Delete button: opens DeleteFaqDialog
7. "Prideti klausima" button also opens FaqFormDialog in create mode
8. Empty state: "Dar nera DUK irasu. Pridekite pirma klausima." centered
