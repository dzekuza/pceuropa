**Install recharts:**
Run `npm install recharts` — recharts is the standard React charting library, works with React 19, SSR-compatible with 'use client' directive on chart components.

**lib/utils/analytics.ts:**
Create pure data aggregation functions (no side effects, easily testable):

1. `aggregateMonthlyRevenue(reports: RevenueReport[]): { month: string; label: string; total: number }[]`
   - Groups reports by month (YYYY-MM), sums amount_eur per month
   - Returns sorted by month ascending
   - `label` is Lithuanian month name from MONTHS_LT (e.g. "Sausis 2026")
   - Fills gaps: if a month in the range has no data, include it with total: 0

2. `aggregateCategoryRevenue(reports: RevenueReport[], tenants: Tenant[]): { category: string; total: number }[]`
   - Joins reports to tenants via tenant_id to get category
   - Groups by category, sums amount_eur
   - Sorted by total descending (highest revenue first)
   - Tenants with null category grouped as "Kita"

3. `getSubmissionStatus(tenants: Tenant[], reports: RevenueReport[], targetMonth: string): { submitted: Tenant[]; pending: Tenant[]; submittedCount: number; totalCount: number }`
   - For a given month (YYYY-MM-01 format), determines which tenants have submitted and which haven't
   - Returns both arrays plus counts for summary cards

4. `getDateRangeMonths(startMonth: string, endMonth: string): string[]`
   - Generates array of "YYYY-MM-01" date strings between start and end (inclusive)
   - Used to fill gaps in chart data

Import types from `@/types/database` and months from `@/lib/constants`.
